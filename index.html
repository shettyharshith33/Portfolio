Streakify

Todo & Habit Tracker

Streakify is a high-performance consistency-tracking Android application developed using Kotlin 1.9.24 and Jetpack Compose to gamify habit formation through a premium, obsidian-themed user interface. The platform integrates Firebase Firestore for real-time synchronization and Remote Config for dynamic management of app limits and maintenance modes. The project features sophisticated 4-tier intensity heatmaps for progress visualization.

Kotlin Jetpack Compose Firebase Firebase Remote Config
